## ipsw dyld o2a

Convert offset to address

```
ipsw dyld o2a <DSC> <OFFSET> [flags]
```

### Options

```
  -d, --dec[=true|false]    Return address in decimal
  -h, --help[=true|false]   help for o2a
  -x, --hex[=true|false]    Return address in hexadecimal
```
