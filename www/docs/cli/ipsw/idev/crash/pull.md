## ipsw idev crash pull

Pull crashlogs

```
ipsw idev crash pull [flags]
```

### Options

```
  -a, --all[=true|false]    Pull all crashlogs
  -h, --help[=true|false]   help for pull
  -o, --output string       Folder to save crashlogs
  -r, --rm[=true|false]     Remove crashlogs after pulling
```
